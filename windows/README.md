# Keyboop для Windows

> **wrong layout? keyboop.** Теперь и на Windows.

Переключатель раскладки, который чинит кракозябры (`ghbdtn` → `привет`) прямо во время
набора и **не трогает буфер обмена**. Плюс голосовой набор, офлайн-перевод, история, сниппеты
и запись звонков — всё на этом компьютере, без облака.

Это полный порт мак-версии. Детектор раскладки, словари, триграммы и все правила, выверенные
отзывами, общие: Rust-ядро [`core/`](core) — построчный перенос `Sources/Keyboop/*.swift`, а
списки слов и словари берутся из тех же файлов, что у мак-версии. Правка в Swift-списке
попадает в Windows-сборку автоматически.

## Что умеет

**Раскладка**

| | |
|---|---|
| Авто-переключение на границе слова | пробел / Enter (Tab — в настройках) |
| Правка на лету | посреди слова, как только сочетание букв невозможно в текущем языке |
| Enter-pre | слово чинится **до** того, как Enter отправит сообщение в чате |
| Ручной хоткей (**Pause**) | последнее слово туда-обратно; если буфер пуст — выделенный текст |
| Регистр выделенного (**Alt+Pause**) | всё в ЗАГЛАВНЫЕ ↔ строчные |
| Обучение на отмене, исключения | слова и программы: «обычно», «мягко», «не трогать», своя раскладка |
| Спорные пары | `yt`/`не`, `nj`/`то`…: по контексту или всегда в одну сторону |
| Опечатки, две заглавные, след Caps Lock | выключены по умолчанию, как на Маке |
| Лампочка Caps Lock — язык | горит — русский (выключено по умолчанию) |

**Голос и текст**

| | |
|---|---|
| Голосовой набор (**правый Alt**) | держите и говорите; или «нажал/нажал». Esc — отмена (текст уйдёт в историю) |
| Два движка | **Whisper** (whisper.cpp, модели base…large-v3-turbo) и **Parakeet TDT v3** (ONNX) |
| Словарь диктовки | «как слышится → как пишется», слова подсказываются распознаванию |
| Перевод выделенного (**Ctrl+Alt+T**) | русский ↔ английский офлайн (OPUS-MT), перевод печатается поверх выделения |
| Сниппеты | автозамена по сокращению и список «по цифре» по хоткею: 1…9, Shift+цифра, Ctrl+цифра, 0 — последняя диктовка |
| Вставка без форматирования (**Ctrl+Shift+V**) | выключена по умолчанию: во многих программах это сочетание уже занято |

**История** (зашифрована DPAPI: прочитать можете только вы на этом компьютере)

| | |
|---|---|
| Диктовки | с записью звука по желанию, поиск, копирование, срок хранения |
| Буфер обмена | по желанию; пароли из менеджеров паролей не записываются |
| Импорт файла | mp3, m4a/aac, wav, flac, ogg: расшифровка с абзацами по паузам, прогресс и отмена |
| Запись звонка | **Shift+щелчок по значку**: системный звук + микрофон, расшифровка в историю |

**Прочее:** окна настроек, истории, приветствия и отзыва; значок раскладки в трее; пауза
«не мешать»; автообновление из GitHub Releases (тихое — по желанию, есть бета-канал).

По умолчанию Keyboop не вмешивается в терминалы и программы с «голыми» горячими клавишами
(Premiere, DaVinci Resolve, Blender, Ableton…), а в редакторах кода работает мягко.

## Установка и запуск

Нужна Windows 10 1607+ (или Windows 11), x64. Установки нет: скачайте
`keyboop-windows-x64.zip` из [релизов](https://github.com/krazzer00/keyboop/releases)
(теги `win-v…`), положите `keyboop.exe` куда угодно и запустите. При первом запуске откроется
приветствие; автозапуск включается в настройках.

Модели не входят в exe и скачиваются кнопкой в настройках (один раз, с проверкой SHA-256),
дальше сеть не нужна:

| что | размер | откуда |
|---|---|---|
| Whisper base / small / medium / large-v3-turbo | 142 МБ … 1,6 ГБ | keyboop.com, запасной — Hugging Face (закреплённая ревизия) |
| Parakeet TDT 0.6B v3 + onnxruntime.dll | ~750 МБ | Hugging Face + релиз ONNX Runtime от Microsoft |
| Перевод ru→en, en→ru | ~310 МБ каждый | Hugging Face (Helsinki-NLP OPUS-MT) |

| где | что |
|---|---|
| `%APPDATA%\Keyboop\` | `settings.json`, `exceptions.json`, `snippets.json`, `text_snippets.json`, `dictionary.json`, `state.json`, `keyboop.log` |
| `%LOCALAPPDATA%\Keyboop\` | история (`history.bin`, зашифрована), записи диктовок, модели |

Лог пишется **без** содержимого набранного и надиктованного: только длины и счётчики.

Файл можно отдать на расшифровку и из проводника: `keyboop.exe --import запись.m4a`.

## Сборка

```bash
# на Windows (MSVC): нужны Rust, CMake и LLVM (clang для bindgen whisper.cpp)
cargo build --release

# кросс-сборка из Linux: mingw-w64 (posix-потоки), cmake, clang
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu

cargo test          # тесты ядра и переносимых частей — на любой ОС
```

Настройки кросс-сборки whisper.cpp (toolchain-файл CMake, заголовок совместимости, статический
libstdc++) лежат в `.cargo/config.toml` и `build/`: exe получается без сторонних DLL.
Сборка читает `../Sources/Keyboop/ExtraWords.swift` и `../Sources/Keyboop/Resources/`,
поэтому нужен весь репозиторий, а не только эта папка.

Сквозные тесты на настоящих моделях включаются переменными окружения:
`KEYBOOP_MT_DIR` (перевод), `KEYBOOP_PARAKEET_DIR` + `KEYBOOP_ORT_DYLIB` +
`KEYBOOP_PARAKEET_WAV` + `KEYBOOP_PARAKEET_EXPECT` (Parakeet).

### Релиз

Тег `win-v<версия>` (версия — из `Cargo.toml`) запускает `.github/workflows/windows-release.yml`:
тесты, сборка, `keyboop-windows-x64.zip` и `.sha256` рядом. Тег с дефисом (`win-v0.5.0-beta.1`)
публикуется как пре-релиз и доходит только до бета-канала. Встроенное обновление берёт архив
только с совпавшим хешем, подменяет exe и перезапускается.

## Как это устроено

- `core/` — всё, что не зависит от ОС: движок раскладки (системное спрятано за трейтом
  `Platform`, поэтому он целиком проверяется тестами на эмуляторе текстового поля), затравки
  и словарь диктовки, история, нарезка длинных записей.
- `app/src/win/hook.rs` — низкоуровневые хуки и **вся** печать замен в одном потоке. Вокруг
  нашей синтетики стоит «забор»: настоящие нажатия, успевшие в очередь раньше пачки замены,
  придерживаются и переигрываются после неё.
- `app/src/win/layouts.rs` — раскладки (HKL) и живая таблица символов из `ToUnicodeEx`.
- `app/src/win/voice/` — запись (WASAPI через cpal), whisper.cpp и Parakeet, импорт файлов и
  запись звонков; `app/src/parakeet.rs` — Parakeet на ONNX Runtime (DLL грузится
  динамически по полному пути), `app/src/mt/` — перевод на candle.
- `app/src/ui/` — окна на egui отдельным процессом (`keyboop.exe --ui settings`), связь с
  главным процессом через `WM_COPYDATA`.
- `app/src/win/clipboard.rs` — буфер обмена трогаем только по явному действию (выделение по
  хоткею, вставка без форматирования) и всегда возвращаем как было, если его никто не сменил.

## Отличия от Мака

- Хоткей по умолчанию — **Pause**, а не ⌥⇧: Alt+Shift в Windows занят сменой языка.
- Запись звонка — Shift+щелчок по значку (на Маке ⌥-щелчок).
- Parakeet работает на процессоре (на Маке — Neural Engine); Whisper остаётся движком по
  умолчанию.
- Лампочка Caps Lock управляется через драйвер клавиатуры; на части систем Windows пускает
  туда только программы, запущенные от администратора.
- Мёртвые клавиши (US-International) и IME буфер набора не видит.
- В программах, запущенных от администратора, Keyboop молчит — Windows не пускает туда
  синтетический ввод от обычного процесса.
